# 🇨🇭 swisspro.tw 省瑞計劃

A Taiwan-focused Switzerland travel planning platform designed to help travelers make smarter decisions when planning their Swiss adventures.

🌐 Website: https://swisspro.tw

## About

SwissPro.tw helps Taiwanese travelers simplify Switzerland trip planning by providing:

- 🚆 Swiss Travel Pass calculators and comparisons
- 🗺️ Interactive itinerary planning tools
- 🏔️ Jungfrau, Zermatt, and mountain pass recommendations
- 🚄 Train route validators (seat reservations, advance booking requirements, pricing)
- 📝 Practical Switzerland travel guides in Traditional Chinese
- 💰 Cost-saving recommendations tailored to each itinerary

The goal is to reduce planning friction for first-time Switzerland visitors and help them understand what tickets they actually need.

## Features

### 🚆 Swiss Travel Pass Calculator

🌐 Website: https://calculator.swisspro.tw

Compare:

- Swiss Travel Pass
- Swiss Half Fare Card
- Individual point-to-point tickets

Based on the user's itinerary to determine the most cost-effective option.

---

### 🚄 Route Validator

🌐 Website: https://calculator.swisspro.tw?p=validator

Check whether a route:

- Requires advance purchase
- Requires seat reservations
- Is covered by Swiss Travel Pass
- Needs additional supplements
- Has important travel considerations

Examples:

- Zurich → Zermatt
- Zermatt → St. Moritz
- Interlaken → Jungfraujoch
