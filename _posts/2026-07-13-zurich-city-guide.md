    <h3>蘇黎世美術館 Kunsthaus Zürich</h3>
    <p>蘇黎世美術館收藏從中世紀到當代的歐洲藝術，展出莫內（有睡蓮）、梵谷、雷諾瓦、畢卡索等人的作品。有趣的是裡面有不少爭議性展品，因為美術館許多館藏為之前蘇黎世軍火商的收藏。這些作品被指控是在二戰的時候偷拿的，所以在館內某些展品旁邊會標明「是不是搶來的」。</p>
    
    <p>如果剛好週三在蘇黎世的話強烈推薦來參觀，因為週三免費入場（只有常設展，但常設展就已看不完）。週三參觀的時候，只需要進去跟他說，哈囉，就可入場，館內地下室有寄物櫃和免費廁所，可以寄放背包等東西，不需要硬幣。</p>
    
    <p>美術館有新館與舊館，就在道路的兩旁，裡面有地下道連通，也可以走外面過馬路，門口就有輕軌和巴士站，站名 Kunsthaus。需注意持 STP「沒有」折扣，蘇黎世卡的話免費參觀。</p>

    <h3>瑞士國家博物館 Landesmuseum Zürich</h3>
    <p>要了解瑞士，不能不去瑞士國家博物館，此館就在蘇黎世中央車站正旁邊，甚至有個專門的出口，只要找指標上寫 Landesmuseum 的那個出口出去直接抵達門口。</p>
    
    <p>從石器時代、中世紀到近代瑞士的各種相關物品一應俱全。持 STP 或蘇黎世卡都免費參觀，冬天的話這邊還有聖誕市集，夏天也有露天電影院，非常適合情侶、家庭一起來走走逛逛。</p>
    
    <p>另外博物館紀念品店有許多很「瑞」的東西（瑞士刀、起司鍋的鍋子、瑞士憲法、明信片等等），適合來尋寶找伴手禮買回去，就算沒有要進去參觀博物館也可逛記念品店。</p>
    
    <p>順便一提，這邊的地下室有免費廁所，如果你在蘇黎世中央車站很想上廁所又不想付 1.5 瑞郎（約 60 台幣），可以到這個博物館樓下上。</p>

    let currentDuration = 24;

    function updateDuration(val) {
        currentDuration = val;
        const btn24 = document.getElementById('btn-24h');
        const btn72 = document.getElementById('btn-72h');
        
        if(val === 24) {
            btn24.style.background = "#D52B1E"; btn24.style.color = "white";

    function calculate() {
        const hasHalfTax = document.getElementById('has-half-fare').checked;
        const isLindtChecked = document.getElementById('item-lindt').checked;
        const days = currentDuration / 24;
        
        const baseCardPrice = (currentDuration === 24) ? 29.00 : 56.00;
        let cardTotalCost = baseCardPrice;
        document.getElementById('card-label').innerText = `買蘇黎世卡 (${currentDuration}h)`;

        let dailyTransport = isLindtChecked ? (hasHalfTax ? 7.20 : 14.40) : (hasHalfTax ? 6.60 : 9.40);
        let individualTotal = dailyTransport * days;

        const items = document.querySelectorAll('.item');
        items.forEach(item => {
            if (item.checked) {
                const fullPrice = parseFloat(item.getAttribute('data-full'));
                const halfPrice = parseFloat(item.getAttribute('data-half'));
                const discountRate = parseFloat(item.getAttribute('data-discount-rate'));
                
                individualTotal += (hasHalfTax ? halfPrice : fullPrice);
                cardTotalCost += (fullPrice * (1 - discountRate));
            }
        });

        document.getElementById('total-individual').innerText = individualTotal.toFixed(2) + " CHF";
        document.getElementById('card-total-cost').innerText = cardTotalCost.toFixed(2) + " CHF";

        const recDisp = document.getElementById('recommendation');

            recDisp.style.backgroundColor = "#e8f5e9"; recDisp.style.color = "#2e7d32";

            recDisp.innerHTML = "❌ 不需要卡 (省 " + diff + " CHF)";
            recDisp.style.backgroundColor = "#ffebee"; recDisp.style.color = "#c62828";
