## 瑞士中部通票 (Lucerne Travel Pass, LTP) 價格

這張票分為 3/4/5/10 天版本，價格如下表，重點：持半價卡或 STP 「沒有」額外折扣。

| 天數 （連續） | 成人 | 小孩（到 16 歲） |
| :--- | :--- | :--- |
| **3 Days** | 240  | 30  |
| **4 Days** | 265  | 30  |
| **5 Days** | 290  | 30  |
| **10 Days** | 365  | 30  |

此票可在琉森附近在指定天數內搭到飽，主要的觀光景點介紹如下。

<a id="main-tourist"></a>
## 主要觀光景點

[官方網站](https://lucernetravelpass.ch/en/inform/line-network)號稱此券可帶你上山下湖，一網打盡。內含一堆相對冷門纜車路線，所有可用的路線皆可在官方網站查看。以下整理此票券所包含的「景點精選」，相對比較大眾為人熟知的地方：

1. 布里恩茨蒸汽火車 (Brienz Rothorn Bahn) 
1. 琉森 ↔ 茵特拉肯 (Luzern Interlaken Express)
1. 石丹峰 Stanserhorn
1. 鐵力士山 Titlis
1. 瑞吉山 Rigi - {% assign target_post = site.posts | where: "url", "/blog/rigi-guide/" | first %}<a href="{{ target_post.url }}" class="swiss-red-link">{{ target_post.title }}</a>
1. 皮拉圖斯山 Pilatus （金色、銀色環遊）
1. 琉森湖遊船
1. 施圖斯 Stoos 最陡纜車

下表整理這些常見的景點價格，含半價卡、STP 及 LTP

| 天數 （連續） | 原價 (瑞郎) | 半價卡 | STP  | LTP |
| :--- | :--- | :--- | | :--- |:--- | 
| 布里恩茨蒸汽火車 （來回）| 98  | 49 | 49  | 0 |
| 琉森湖遊船 （一日票，夏天）| 86 | 43 | 0  | 0 |
| 琉森 - 茵特拉肯 （單程）| 34  | 17 |  0 | 0 |
| 石丹峰（纜車來回） | 82  | 41 | 0  | 0 |
| 瑞吉山（一日票，琉森出發） | 131  | 65.5 | 0  | 0 |
| 鐵力士山 | 102 | 51 | 51  | 0 |
| 施圖斯 Stoos （最陡纜車來回） | 23.2  | 11.6 | 0  | 0 |
| 皮拉圖斯金色環遊 | 119.8  | 59.9 |  42  | 0 |

由上表可看出，這張 LTP 和 STP 在琉森地區重疊性非常高。主要差異為：布里恩茨蒸汽火車、鐵力士山和皮拉圖斯山這三個可以免費搭乘，這是其他票券都無法免費的路線。（除了[伯恩高地通票](https://swisspro.tw/blog/berner-oberland-pass/)可以免費搭乘布里恩茨蒸汽火車。）

## 範例行程

下表簡單整理如何用 LTP 來省省遊瑞士。以下是省瑞先生琉森附近的四日遊，每天都住琉森，範例 4 天 LTP 行程推薦如下，D1 為第一天行程，依此類推

| 路線 | 原價 | 半價卡 | STP | LTP |
| :--- | :--- | :--- | :--- | :--- |
| D1 琉森 ➔ 布里恩茨  | 30 | 15 | 0  | 0 | 
| D1 布里恩茨蒸汽火車 | 98 | 49 | 49  | 0 | 
| D1 布里恩茨 ➔ 琉森 | 30 | 15 | 0  | 0 | 
| D2 琉森 ➔ 恩格堡 | 18.2 | 9.1 | 0 | 0 |
| D2 恩格堡 ➔ 鐵力士山 （來回）| 102 | 51 | 51 | 0 |
| D2 恩格堡 ➔ 琉森 | 18.2 | 9.1 | 0 | 0 |
| D3 琉森 ➔ 皮拉圖斯金色環遊 | 119.8  | 59.9 |  42  | 0 |
| D4 琉森 ➔ 石丹峰（來回）| 82  | 41 | 0  | 0 |
| D4 琉森 ➔ 茵特拉肯 | 34  | 17 |  0 | 0 |
| 總計 | 532.2 | 266.1 | 142  | 0 |

第四天之後就可從茵特拉肯開始少女峰行程。因為這個範例行程完全是為 LTP 打造，全部景點都免費，非常划算。加上票券本身價格的話，總結如下表

| 票券 | 票券價格 | 車票總價 | 總共 |
| LTP 4 天 | 265 | 0 | **265** |
| 半價卡    | 150 | 266.1 | 416.1 |
| STP 4 天 | 309 | 142 | 451 |

但如果後續加上少女峰、策馬特等行程，可能就不一定。因為半價卡或更多天的 STP 可以去更多地方，而 LTP 一出琉森地區就幾乎沒用了。
